# ⚠️ QUYỀN LỰC TUYỆT ĐỐI: DOCKER ONLY

## Quy Tắc Phát Triển

**BẮT BUỘC:**
- ✅ Chạy trên Docker port 3000
- ✅ Dùng `docker-compose up -d` để start
- ✅ Dùng `docker-compose restart frontend` sau khi sửa code

**CẤM:**
- ❌ `npm run dev` local
- ❌ Port 5173 hoặc bất kỳ port nào khác 3000
- ❌ Chạy backend/database riêng lẻ

## Quick Start

```bash
# Lần đầu
docker-compose up --build

# Hàng ngày
docker-compose up -d

# Sau mỗi lần sửa code
docker-compose restart frontend
# Rồi refresh browser (F5)
```

## Tại Sao?

- Đồng bộ môi trường toàn team
- Backend + Database + CV đã tích hợp
- Tránh "works on my machine"
- Restart container chỉ mất 3 giây
