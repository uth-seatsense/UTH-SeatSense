# Tài liệu dự án

- [Điều lệ dự án v1.2](project-charter.md)
- `requirements/` lưu phạm vi, yêu cầu và các ca sử dụng.
- `architecture/` lưu thiết kế hệ thống, mô hình dữ liệu và hợp đồng API.
- `decisions.md` ghi lại các quyết định kỹ thuật quan trọng.
- `test-plan.md` và `test-report.md` ghi lại kế hoạch và kết quả kiểm thử.
- `meeting-notes/` và `reports/` lưu biên bản họp và báo cáo dự án.
